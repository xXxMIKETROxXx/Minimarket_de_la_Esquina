Proyecto académico de desarrollo web para **Minimarket La Esquina**, desarrollado como parte de la asignatura de desarrollo de software. El proyecto consiste en la creación de un sitio web para un minimarket de una sola sucursal, orientado a mejorar la presentación de sus productos y facilitar la interacción con clientes y administradores.

El sitio cuenta con páginas públicas de inicio, productos, detalle de productos, registro, inicio de sesión, información del negocio, blogs y contacto. También incorpora un área administrativa destinada a la gestión de productos y usuarios, además de validaciones de formularios mediante JavaScript, manejo de regiones y comunas, control de stock crítico y almacenamiento de información.

El desarrollo se realizó utilizando **HTML, CSS y JavaScript**, manteniendo una estructura sencilla y acorde con los contenidos trabajados en clases. El proyecto fue desarrollado y editado principalmente utilizando **Visual Studio Code** y **GitHub**, tomando como referencia la pauta y los ejemplos entregados por el docente.

Este repositorio contiene los archivos correspondientes al desarrollo frontend del proyecto, incluyendo las páginas HTML, hojas de estilo CSS, scripts JavaScript e imágenes utilizadas en el sitio.
